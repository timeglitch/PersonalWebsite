# frankzhang.org

Personal site. React + TypeScript + Vite. Deployed from GitHub to Cloudflare
Pages, which builds and serves `dist/` — so only files reachable from
`index.html`, or copied verbatim out of `public/`, ever reach the web.

```bash
npm install
npm run dev       # local server on :5173
npm run check     # validate the microfiche sheet
npm run lint
npm run build
npm run capture   # re-photograph the live project sites (see below)
```

## The microfiche viewer

The desktop layout is a microfiche viewer: one large contact sheet of film with
every project printed on it, seen through a lens that pans around. The design
brief and the decisions behind it are in [MICROFICHE_PLAN.md](MICROFICHE_PLAN.md).

```
src/
  projects.ts                 the five projects — the site's content, imports nothing
  microfiche/
    index.ts                  what the folder exposes: MicroficheViewer, clusters
    sheetData.ts              every cell and its coordinates; clusters derived from them
    SheetCell.tsx             how each kind and variant draws
    MicroficheViewer.tsx      the lens: travel, dragging, keyboard, sound
    microfiche.css
public/microfiche/
  captures/                   generated by `npm run capture` — do not put anything here by hand
  archive/                    hand-placed images
```

Two ideas carry the whole thing:

- **The sheet is one fixed coordinate space**, 34 × 20 units, where 1 unit is
  100px at 1× magnification. Every item is a **cell** placed with `x`, `y`, `w`,
  `h` in units. Nothing ever moves.
- **The lens moves instead.** The viewer holds `{x, y, zoom}`, where `x, y` is
  the point on the sheet at the centre of the window, and turns it into a single
  CSS transform on the sheet element.

## Adding something to the sheet

### 1. Put the image where it belongs

Hand-placed images go in `public/microfiche/archive/`. **Not** in `captures/` —
`npm run capture` deletes and rebuilds that whole folder, so anything you add
there disappears on the next refresh.

Flatten transparency to white first, or the film's black ground shows through:

```bash
sips -s format jpeg -s formatOptions 92 diagram.png --out \
  public/microfiche/archive/diagram.jpg
```

### 2. Add a cell to `sheetData.ts`

Every cell needs an `id`, a `kind`, and geometry. Everything else depends on the
kind.

| kind | what it is | needs |
|---|---|---|
| `capture` | an image file | `src`, `label` |
| `plate` | drawn in code | `variant`, usually `title` and `lines` |
| `clipping` | the newspaper description | `headline`, `body` |
| `cover` | the index card | nothing — built from the project record |

Two optional flags change what a cell *means* rather than how it looks:

- **`project`** — tag it with a project id and it joins that cluster: it
  brightens when that project is selected, and clicking it centres that project.
  Leave it off and the cell is a *transitional artifact*, filling the routes
  between clusters.
- **`framed`** — mark it and it joins the block the lens fits when that project
  is selected. The bounding box of a cluster's framed cells is what gets
  centred, so this is the one knob that shapes a project's view.

A worked example — a diagram belonging to Vocalize, sitting just outside the
frame so it's found by panning:

```ts
{
    id: "voc-lpc",
    kind: "capture",
    project: "vocalize",
    fit: "contain",
    src: `${ARCHIVE}/lpc-source-filter.jpg`,
    label: "lpc · source–filter model",
    x: 2, y: 7.05, w: 4.4, h: 1.75,
},
```

### 3. Pick coordinates that don't collide

Cells are positioned by hand, and an overlap doesn't raise an error — it just
looks subtly wrong. Find a gap near the cluster the cell belongs to, leave at
least 0.15 units of clearance, then:

```bash
npm run check
```

It reports overlapping cells, cells off the sheet, duplicate ids, images that
don't exist, and clusters that frame nothing. Run it after moving anything.

### 4. Choose the image treatment

Captures print two ways, because screenshots and diagrams are different kinds of
picture:

- **Screenshots** use the default. They fill the cell, crop to fit, and are
  *screened* onto the dark film — the blend that lightens, which makes a bright
  web page glow against black.
- **Diagrams** set `fit: "contain"`. They are shown whole, never cropped, and
  *multiplied* over paper instead — the blend that behaves like ink, leaving
  white untouched so black line art stays black. Any empty space around the
  figure ends up the same colour as the card.

Set the cell's proportions near the image's own, or `contain` will leave wide
bands of blank card.

### 5. Look at it

`npm run dev`, then click the project in the list. Cells outside the frame are
dimmed until their project is selected.

## Adding a new plate variant

Only needed when a cell should be *drawn* rather than photographed.

1. Add the name to `PlateVariant` in `sheetData.ts`.
2. Add a `case` to `Plate` in `SheetCell.tsx`. Wrap the contents in `<Body>`,
   which supplies the card and its title — pass `style` for the stylesheet block
   to print with. Several variants deliberately share one, so a plain ruled list
   can reuse `style="record"` and need no new CSS at all.
3. Style `.fiche-<style>` in `microfiche.css` if it needs its own treatment.

Drawn plates stay sharp at any magnification, which is why the vowel chart, the
occupancy bars and the equipment record are code rather than images.

## Refreshing the site captures

`npm run capture` drives a headless browser over the four public project sites
and re-photographs them into `public/microfiche/captures/`. The images are
committed deliberately — the viewer shows an archived moment, not a live feed,
and several of the sites refuse to be embedded.

Two things in `scripts/capture-sites.mjs` are worth knowing before re-running
it: the parking site's collector stopped in April 2026, so its capture steps the
chart back to the last month with data rather than photographing an empty grid;
and the satellite tracker gets a long settle delay so its WebGL globe has drawn
a frame worth capturing.
